# Вес

Личное Android-приложение: само сохраняет взвешивания с Xiaomi Mi Body Composition Scale 2,
считает тренд как Libra и состав тела как Zepp Life, пишет данные в Health Connect
и выгружает их в FIT для Garmin Connect.

## Как это работает

- **Весы.** Приложение слушает Bluetooth-трансляции весов (сервис 0x181B). Сопряжение не нужно,
  Zepp Life может оставаться установленным. После привязки весов система будит приложение,
  когда весы что-то передают, даже если оно закрыто.
- **Состав тела** считается по импедансу формулами Xiaomi в реализации openScale
  (жир, вода, мышцы, кости). Нужны рост, пол и дата рождения.
- **Тренд**: экспоненциальное сглаживание с постоянной времени 7 дней. На реальном экспорте Libra
  совпадает со столбцом «weight trend» во всех строках.
- **Health Connect**: записываются вес, процент жира и костная масса новых взвешиваний
  с весов и ручных. Импортированная история не записывается.
- **Garmin Connect**: новые взвешивания отправляются сами (неофициальный способ, как в
  python-garminconnect 0.3: вход на странице Garmin во встроенном браузере, DI OAuth2-токены,
  загрузка FIT в upload-service). Историю можно выгрузить FIT-файлом и загрузить на
  connect.garmin.com/app/import-data.
- **Графики**: вес, жир, вода, импеданс и ИМТ, у каждого свой тренд. Показатели состава тела
  берутся только из утренних взвешиваний (04:00–11:00), остальные помечаются. Для истории Zepp
  импеданс восстановлен обращением формулы Xiaomi.
- **Энергобаланс и цель**: ккал/день по наклону тренда за 4 недели (× 7700 ккал/кг), комментарий
  по правилам относительно цели (в коридоре / не хватает / слишком быстро / не в ту сторону / плато),
  перевод разницы в еду и шаги.
- **Базовый обмен** по формуле Катча–Макардла (370 + 21,6 × безжировая масса).
- **Анализ**: шаги и сон из Health Connect за полгода по неделям рядом с балансом энергии (баланс недели —
  по средним весам соседних недель; вердикт учитывает разброс между неделями).
- **Отчёт для консультации**: текст за 8 недель (вес, баланс, цель, состав тела, шаги, сон, активные калории,
  тренировки, еда и белок из Health Connect, расчётный реальный расход) — «Поделиться» или «Копировать».
- **Libra**: импорт CSV-экспорта (с удалением дублей старого формата) и резервная копия в том же формате.

## Сборка

Каждый push собирает APK в GitHub Actions; последняя сборка всегда по адресу
`releases/latest/download/WeightTrend.apk`.
APK подписывается постоянным ключом из секрета репозитория `WEIGHTTREND_KEYSTORE`
(ключ в base64), поэтому новые версии ставятся поверх старых без потери данных.
Сам ключ в репозиторий не попадает.

Требуется Android 12+.
