# Вес

Личное Android-приложение: само сохраняет взвешивания с Xiaomi Mi Body Composition Scale 2,
считает тренд как Libra и состав тела как Zepp Life, пишет данные в Health Connect
и выгружает их в FIT для Garmin Connect.

## Как это работает

- **Весы.** Приложение слушает Bluetooth-трансляции весов (сервис 0x181B). Сопряжение не нужно,
  Zepp Life может оставаться установленным. После привязки весов система будит приложение,
  когда весы что-то передают, даже если оно закрыто.
- **Состав тела** считается по импедансу формулами Xiaomi в реализации openScale
  (жир, вода, мышцы, кости). Нужны рост, пол и дата рождения.
- **Тренд**: экспоненциальное сглаживание с постоянной времени 7 дней. На реальном экспорте Libra
  совпадает со столбцом «weight trend» во всех строках.
- **Health Connect**: записываются вес, процент жира и костная масса новых взвешиваний
  с весов и ручных. Импортированная история не записывается.
- **Garmin**: пока через FIT-файл (Настройки → Garmin), который загружается на
  connect.garmin.com/app/import-data.
- **Libra**: импорт CSV-экспорта (с удалением дублей старого формата) и резервная копия в том же формате.

## Сборка

Каждый push собирает APK в GitHub Actions (вкладка Actions → последний запуск → Artifacts).
APK подписывается постоянным ключом из секрета репозитория `WEIGHTTREND_KEYSTORE`
(ключ в base64), поэтому новые версии ставятся поверх старых без потери данных.
Сам ключ в репозиторий не попадает.

Требуется Android 12+.
